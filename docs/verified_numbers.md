## การตรวจสอบความตรงกัน (reconciliation)

`audit.load_reconciliation` บันทึกแถวใน lake เทียบแถวใน dw ทุกตารางทุกรอบโหลด ผลรอบล่าสุดตรงกันทุกตาราง (`matches = true`)
ตาราง Airflow audit แสดง `load_star_schema` แถวเข้า 4,919,260 ต่างจากแถว fact 4,917,880 อยู่ 1,380 แถว
ซึ่งสันนิษฐานว่าเป็นแถวของตาราง dimension (ยังไม่ได้แยกยืนยัน) ตัวเลขข้อมูลจริง (fact) ไม่ได้หาย

## ช่องว่างของข้อมูล (ไม่เติมค่า ไม่ประมาณ)

ความครบวัดจาก `mart.v_pm25_coverage_month` = ชั่วโมงที่มีค่า PM2.5 จริง ÷ (234 สถานี × ชั่วโมงในเดือน)
เฉลี่ยทั้งช่วง 2022–2025 ≈ **40%** ซึ่งต่ำโดยธรรมชาติ เพราะสถานีเปิดและเลิกรายงานไม่พร้อมกัน

| เดือน | ความครบ | สาเหตุ |
| --- | --- | --- |
| 2022-07 | 0% (ไม่มีแถวเลย) | ไม่มีข้อมูลในไฟล์ต้นทาง |
| 2022-08 | 0% (1 สถานี) | ไม่มีข้อมูลในไฟล์ต้นทาง |
| 2025-07 | 0.1% | ไม่มีข้อมูลในไฟล์ต้นทางเกือบทั้งเดือน |
| 2022-06, 2022-09, 2022-02 | 9–18% | ต้นทางมีข้อมูลบางส่วน |
| 2023-03, 2023-12, 2025-08 | 14–18% | ต้นทางมีข้อมูลบางส่วน |
| 2026-01 | 2.8% | อยู่นอกช่วงที่กำหนด (หลัง 2025-12-31) ไม่ใช้ในการวิเคราะห์ |

ข้อควรระวังเวลาอ่านผล: ค่าเฉลี่ยรายเดือนของเดือนที่ความครบต่ำมาจากสถานีเพียงบางส่วน เปรียบเทียบข้ามเดือนต้องระวัง
เดือนที่ไม่มีข้อมูลแสดงเป็นช่องว่างในกราฟ ไม่ถูกเติมค่า

## ข้อจำกัดอื่น

- ค่าเกณฑ์ PM2.5 มาตรฐานไทย 37.5 µg/m³ (24 ชม.): ยืนยันจากหัวข้อข่าว สผ. (onep.go.th) ว่าปรับจาก 50 เป็น 37.5 ตามมติ กก.วล. 2565 แต่ยังไม่ได้อ่านประกาศฉบับเต็มและวันมีผลบังคับใช้ (ใน `mart.pm25_threshold` ยังมีแท็ก VERIFY)
- GISTDA เป็นค่าที่โมเดลประมาณ ไม่ใช่การวัดจริง และมีเพียงไม่กี่วัน จึงไม่ถูกใช้ในกราฟแนวโน้ม
- จังหวัดในหน้าเว็บมาจากการจับพิกัดสถานีกับขอบเขตจังหวัดของ geoBoundaries (OpenStreetMap, ODbL 1.0) ไม่ได้มาจาก OpenAQ โดยตรง หลายจังหวัดมีสถานีเดียว
- ความสัมพันธ์ระหว่างจุดความร้อนกับ PM2.5 (Spearman ≈ 0.63–0.68) เป็นความสัมพันธ์ ไม่ได้พิสูจน์สาเหตุ
